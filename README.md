# 家歴タイムライン（home-timeline）

住宅の「家歴」（住宅履歴情報）を時系列で一覧するための Web アプリです。
[timeline](../timeline)（歴史タイムライン）の描画エンジンをベースに、家づくりと住まいの管理に必要な表示を加えています。

- 購入・設置（▲）と廃棄・交換（✕）
- 修繕（●）、増改築・リフォーム（◆）、点検・メンテナンス（■）、契約・保証・保険（★）の履歴
- 対応年数（点線のバー）と、超過した期間（赤いバー・「要対応」）
- メンテナンス予定（中抜きの記号）。周期（例：5年ごと）から自動で作成
- 交換前後の項目を金色の破線でつなぐ（給湯器、外壁塗装、家電の買い替えなど）
- 住人の履歴：誕生・死亡、結婚、入園・入学、卒園・卒業、就職・転職を、居住期間のバーの上に表示。年齢も計算

## 使い方

`index.html` をブラウザーで開くだけで動きます（D3.js は CDN から読み込むためネットワークが必要です）。
サンプルは `index.html#sample_house` です（架空の戸建て）。

| 操作 | 内容 |
|---|---|
| グラフをクリック / `←` `→` | その月を選択（1か月ずつ移動）。右のパネルに経過年数と、その月の出来事を表示 |
| バー・記号にホバー | 取得費用、対応年数、履歴、予定を表示 |
| `+` `-` `0` | 横軸の拡大・縮小・リセット |
| `F` / `Space` | 選択月に存在する項目だけ表示 |
| 区分フィルター | 構造・設備・家電などで絞り込み |
| 年月順 / 区分別 | 並び替え（交換前後の項目は常に隣り合わせ） |

## データの作り方

`data/` に 1 ファイル 1 家歴で追加し、`index.html` の `data/sample_house.js` の次の行に `<script>` を足します。

```js
DATASETS.my_house = {
  kind: 'home', monthly: true,          // 家歴は必ずこの2つ
  name: '○○邸', period: '2013年4月〜現在', unit: '項目',
  horizonYears: 15,                     // 現在から何年先まで表示するか
  labels: { age: '年', lifespan: '使用期間', agePanel: 'その時点の経過年数' },
  categories: { '設備': '#c0392b', '構造・外装': '#2471a3' },
  persons: [
    { name: 'ガス給湯器', title: '24号', cat: '設備',
      birth: '2013-04',                 // 購入・設置
      death: '2023-09',                 // 廃棄・交換（省略すると「使用中」）
      lifeYears: 10,                    // 対応年数（目安）
      cost: 180000, vendor: '○○設備',
      endLabel: '故障のため交換',
      records: [{ date: '2019-12', type: 'repair', name: '部品交換', cost: 28000 }] },
  ],
  events: [{ year: '2013-04', name: '入居' }],
};
```

### persons の項目

| 項目 | 内容 |
|---|---|
| `name` / `title` / `cat` | 名前、補足、区分（`categories` のキー）。**必須** |
| `birth` | 購入・設置・取得（`"YYYY-MM"`）。住人は入居または誕生。**必須** |
| `death` | 廃棄・交換・終了。省略すると使用中。未来の日付なら終了予定（例：ローン完済） |
| `lifeYears` | 対応年数。現在までを実線、残りを点線で表示し、超過すると赤くなる |
| `cost` / `vendor` / `note` | 取得費用（円）、施工・販売元、備考 |
| `startLabel` / `endLabel` | ▲・✕ の呼び名（例：竣工・引渡し、保証満了） |
| `succeeds` | 交換前の項目名。金色の破線でつなぎ、並びも隣り合わせになる |
| `records` | 履歴と予定。`date`、`type`、`name`、`cost`、`vendor`、`note`、`planned` |
| `cycleYears` | 周期メンテナンス。最後に実施した日から `cycleYears` ごとの予定を自動作成（`cycleType`、`cycleName`） |

`records` の `type` は `repair`（修繕）、`reform`（増改築・リフォーム）、`inspect`（点検）、`warranty`（契約・保証・保険）です。
未来の日付、または `planned: true` は「予定」になり、予定の日付が過去のままなら「実施時期を超過」として赤の破線で表示します。
`recordTypes` を定義すると記号の種類を追加できます。

### 住人の履歴

住人も 1 行 1 人で、`resident: true` を付けます。バーは居住期間を表します。

```js
{ name: '長男', cat: '住人', resident: true,
  birth: '2014-06', born: '2014-06',          // birth＝入居または誕生、born＝生年月（年齢の計算用）
  startType: 'birth', startLabel: '誕生',      // 左端の記号を誕生（✿）にする
  records: [
    { date: '2020-04', type: 'enroll',   name: '入学（小学校）' },
    { date: '2026-03', type: 'graduate', name: '卒業（小学校）' },
  ] },
{ name: '祖母', cat: '住人', resident: true,
  birth: '2016-10', born: '1944-11',           // 2016年10月に同居を開始
  death: '2024-03', endType: 'death', endLabel: '死亡' }   // 右端の記号を死亡（†）にする
```

| `type` | 意味 |
|---|---|
| `birth` / `death` | 誕生 / 死亡（`startType`・`endType` で左右端の記号にも使える） |
| `marriage` | 結婚 |
| `enroll` / `graduate` | 入園・入学 / 卒園・卒業 |
| `career` | 就職・転職 |

住人の右側には年齢（死亡済みなら「N歳で死亡」）が出ます。未来の日付の入学・卒業は予定（中抜き）になります。
パネルとツールチップでは、年齢を `born` から計算します。

## 参考にした資料と注意

- 国土交通省「住宅履歴情報の整備と活用について」: 新築時の図面・建築確認書類、点検結果、リフォーム・修繕の記録、使用製品の情報を蓄積する考え方
- 住宅履歴情報蓄積・活用推進協議会「いえかるて」: 住まいの履歴書として、設計図書や修繕履歴を残す考え方。定期点検の時期は入居1年・2年・5年・10年、以降5年ごとが目安

どちらの資料にも、部位ごとの交換・更新の目安年数は載っていません。
サンプルの `lifeYears` は一般的な目安として仮置きした値です。実際の時期は、製品の仕様や施工会社の診断で確認してください。
